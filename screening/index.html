Model-generated data

Expression profiles for specified conditions

Define a panel of cytokine combinations in a specified CD4 T-cell context. Generate cell profiles for each condition, then analyze the expression matrix to compare predicted responses.

Multiple profiles describe a predicted population, including its average, variation, and cell states. Increasing the number of generated cells refines this estimate; it does not add experimental evidence.

Inputs and outputs

Input: cytokine identities and contextual variables supported by the model.

Output: predicted expression over the documented gene set, with condition labels and generation settings.

Keep generated and measured cells distinguishable in files and figures.

Screen design

Define the response before ranking conditions

Choose a scoring rule: similarity to a reference profile, expression of a gene program, or the proportion of a cell state. Specify the genes, expression scale, and reference population before comparing candidates.

Apply the rule consistently and inspect the genes or populations behind each score. An expression target does not by itself establish a change in cell function.

Record which combinations and cellular contexts were present in training. Keep predictions of unmeasured conditions distinct from reconstructions of measured ones.

Prediction assessment

Evaluate rankings against measured responses

Apply the scoring rule to held-out measurements and compare their ranking with the predicted order. Accurate average expression does not guarantee accurate ranking of candidates.

Choose the criterion and tune the model without using the final test data.

A reproducible screen

Keep the candidate list, model and data versions, split assignments, and scoring code with the results. Document how uncertainty estimates were obtained.

Experimental follow-up

Measure selected combinations

Measure responses to selected conditions with CytoLoom, our experimental screening platform. Preserve the original predictions before examining the measurements, and assign a new version to any model retrained on them.
