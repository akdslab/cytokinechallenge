Project scope

Cytokine perturbations
in CD4 T cells

Cytokine Challenge is a Biohub-led project for measuring and predicting immune-cell responses to cytokines. It brings together a CD4 perturbation dataset, a response model, and a screening platform for experimental validation.

The dataset covers individual cytokines and sampled combinations, starting from naïve CD4 T cells. CD8 T cells, B cells, and monocytes are coming soon.

Context in perturbation prediction

Project information

Frequently asked questions

Where can I access the dataset?

The dataset page collects access and documentation links as they are integrated into the site.

What is the prediction task?

Predict gene expression for cytokine combinations excluded from training. The modeling guide describes evaluation; official split files and scoring rules remain to be documented.

What biological background is required?

Start with the biology primer. The baseline tutorial requires basic Python familiarity and uses only the standard library.

What does cytokine programming mean here?

Changing cell state through exposure to cytokines. Here, we measure gene expression and predict responses to individual cytokines and combinations.

How should predictions be interpreted?

Use predictions to select conditions for experimental measurement. Expression alone does not establish a functional change; the validation overview describes supporting experiments.
