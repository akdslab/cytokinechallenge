Run a tutorial with a coding assistant

Use a coding assistant to run the additive baseline, inspect its predictions, and explain the evaluation.

01 / Prepare the files

Open a local project folder

Download the Python example into a new folder. Open it in a coding assistant with file and terminal access.

Use Python 3.9+; no additional packages are required. The notebook runs the same code in Jupyter.

02 / Run the analysis

Give the assistant the task

Copy this request into the assistant after opening your project folder.

Work in the current project folder. Read cytokine_baseline.py and
explain its inputs, model, train/test split, and evaluation metric.

Check the Python version, then run the existing synthetic example:
python3 cytokine_baseline.py --output-dir assistant-demo

Keep the source file unchanged. Report the command you ran and the
paths of synthetic_cells.csv and synthetic_metrics.json.

Inspect the saved results and check that:
- each held-out cytokine combination is absent from training;
- controls and individual-signal effects are estimated from training data;
- predictions are compared with donor-condition mean expression;
- the additive and control-only baselines use the same test observations.

Explain the difference between the two reported errors, what the
invented interaction demonstrates, and why this evaluation does not
measure prediction of the full distribution of single-cell responses.
Describe any execution error before proposing a change.

Find the two output files in assistant-demo. If they are missing, check the assistant's access to the folder and Python.

03 / Review the output

Check the analysis record

Outputs from the supplied Python example
OutputWhat to check
synthetic_cells.csvCell identifiers, donor labels, cytokine sets, expression features, and train/test assignments.
synthetic_metrics.jsonAdditive and control-only errors, with observed and predicted mean expression for each donor–condition group.
Run command and explanationThe Python command, output paths, prediction target, split, and limitations of the metric.

Comparing the additive and control-only errors tests whether individual effects help predict these synthetic combinations. It does not establish performance on biological data.

Check the explanation against the baseline definition, evaluation procedure, and glossary.

04 / Adapt the analysis

Provide the experimental metadata

For a small processed cell table, save the adaptation notebook beside the Python file. Supply the filename and column definitions listed here.

Check the CD4 dataset documentation for expression scale and experimental context. Reserve final test combinations before model selection, and fit learned preprocessing on training observations.

Download the adaptation notebook ↓

Information to supply

  • The input filename, format, and expression features.
  • Cell identifiers and donor or sample labels.
  • Cytokine identities, combination labels, and the control label.
  • Dose, exposure duration, activation conditions, and batch information.
  • The selected cell population, preprocessing steps, and expression scale.
  • The combinations reserved for validation and final testing.

The CSV notebook is intended for small tables. For large sparse expression matrices, use a loader that preserves sparse storage.
