An additive model of cytokine responses

Predict responses to pairs of signals by adding their individual effects, then evaluate combinations excluded from training.

Download notebook ↓ Download Python ↓

On this pageSetupInput dataAdditive modelEvaluationData preparation
This synthetic example has three invented signals, six expression features, and three donor labels. Its teaching format and error metric are separate from the experimental dataset and benchmark specifications.

SETUP

Run the example

Download the Python file and run this command in its folder. The script requires Python 3.9+ with no additional packages. It writes cells and evaluation results to demo-output.

Run the Python blocks below in order, in one session from the same folder.

python3 cytokine_baseline.py --output-dir demo-output

Alternatively, open the notebook in Jupyter and run its cells in order. It includes all required code.

01 · INPUTS

Inspect cells and conditions

Each row represents a cell, its signals, and one expression value per gene.

Single-cell RNA sequencing measures different cells in each condition. Treatment effects are estimated by comparing treated and control populations, without before-and-after measurements of the same cell.

Each synthetic donor contributes control cells, three individual-signal conditions, and three signal-pair conditions. Other variables are held fixed.

Fields used in this example
FieldMeaning
cell_idUnique observation identifier
donorLabel for the biological source
cytokinesA set of signals; an empty set is the control
expressionGene → value, in arbitrary expression units
from cytokine_baseline import make_synthetic_rows, canonical_condition

rows = make_synthetic_rows(seed=7)
conditions = {canonical_condition(row["cytokines"]) for row in rows}
print(f"{len(rows)} cells, {len(conditions)} conditions")
print(rows[0])

In experimental data, also check dose, exposure duration, batch, quality control, and expression scale. Cytokine names alone do not define a condition.

02 · MODEL

Fit changes relative to control

For each donor, subtract mean control expression from the mean for each individual signal. To predict A + B, add both changes to the control mean.

The model cannot represent interactions in which one signal changes the response to another. Additivity also depends on expression scale: adding raw values and adding log-transformed values give different predictions.

ADDITIVE PREDICTION

change(A) = mean(A) − mean(control)

prediction(A + B) = mean(control)
+ change(A) + change(B)

Compute means within the same donor and context, using training observations only.

from cytokine_baseline import split_by_condition, fit_additive

held_out = [
    ("signal_A", "signal_B"),
    ("signal_A", "signal_C"),
    ("signal_B", "signal_C"),
]
train, test = split_by_condition(rows, held_out)
model = fit_additive(train)
prediction = model.predict("toy_donor_1", ("signal_A", "signal_B"))

The output is one predicted mean per gene, donor, and condition. It does not estimate variation between cells.

03 · EVALUATION

Hold out complete combinations

Exclude all A + B cells from training across every donor; A + B and B + A are the same condition. A random cell split can place the same combination in both sets and does not test prediction of an unseen combination.

Test donors occur in training. This donor-specific baseline cannot predict an unseen donor. A separate donor-generalization task must specify whether that donor’s control profiles are available at prediction time.

Mean expression error

Average test cells within each donor and condition. Compute root mean squared error across genes, then average those errors equally across donor–condition groups.

Mean expression error does not measure variation between cells or the frequency of rare responses.

from cytokine_baseline import evaluate

train_conditions = {canonical_condition(row["cytokines"]) for row in train}
test_conditions = {canonical_condition(row["cytokines"]) for row in test}
assert train_conditions.isdisjoint(test_conditions)

result = evaluate(model, test)
print("Additive RMSE:", round(result["rmse_additive"], 3))
print("Control-only RMSE:", round(result["rmse_control_only"], 3))

The control-only baseline predicts no expression change. Lower additive error shows that individual effects help predict the combinations. The simulation includes an A + B interaction that the additive model cannot represent.

Additional evaluation considerations

Report expression and treatment-change errors by donor and condition. Evaluate cell-state distributions when the model predicts them.

Fit learned preprocessing and select features using training data. Keep validation combinations separate from final test combinations, and fix the evaluation plan before inspecting test performance.

Cells from one donor are not independent biological replicates. Base uncertainty estimates on donor and experimental replication.

DATA PREPARATION

Adapt the example to experimental data

The adaptation notebook reads a small, processed cell table from a CSV file. Specify its column names, control label, expression features, and held-out combinations.

Download the adaptation template ↓

Required preparation

  1. Identify the input format and metadata fields.
  2. Select a consistent cell population, dose, time point, and expression scale.
  3. Check condition labels and donor coverage.
  4. Keep the controls and individual-signal observations needed for prediction in training.
  5. Record preprocessing choices and the split.

For large sparse expression matrices, use a loader that preserves sparse storage. The CSV template is intended for small tables.
